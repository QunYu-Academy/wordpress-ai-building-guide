# WordPress AI 对话式建站教程

这本教程写给第一次用 Codex 做外贸网站的人。你提供产品、客户和业务资料，跟着书里的对话示例选设计、做页面，再到 WordPress 后台试改一项内容，检查网站是否真的能用。

[阅读《WordPress AI 对话式建站教程》PDF（v44，64 页）](./WordPress_AI对话式建站教程_v44_配套2.39.22-r15.pdf)

**动手前准备**：本仓库提供教程 PDF。安装步骤还需要单独取得 WordPress Builder 用户 ZIP，教程对应版本为 `2.39.22-r15`。

## 按你手上的任务翻页

| 现在想做什么 | 页码 | 跟着完成一件事 |
| --- | --- | --- |
| 第一次建站 | 7–13 | 建一个项目文件夹，把配套 ZIP 交给 Codex，再用自己的产品、客户和建站目标发起第一次对话。 |
| 规划页面、选设计 | 23–36 | 看书里怎样从挖掘机买家的搜索问题整理页面清单，再选首页与内页设计。 |
| 检查网站能否自己维护 | 39–41 | 在后台改一项真实产品参数，保存后重开，再到对应的产品页核对。 |
| 上线并接收询盘 | 42–47 | 在审核网址提交带唯一标记的测试询盘，用同一标记去后台和收件箱核对，再绑定正式域名。 |
| 给已有网站更新内容 | 48–58 | 按任务找对应页。比如新增一个产品型号看第 49 页，上传一篇文章看第 52 页，调整导航看第 56 页。 |

第 4–6 页是按任务编排的目录。打开 PDF 后可直接点页码跳转，把书里提示词的示例内容换成自己的业务资料。
